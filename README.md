# 📦 EPPS Supply Chain Container Optimizer

A specialized tool designed to optimize container loading and supply chain logistics. This application provides intelligent calculations to maximize space efficiency, reduce shipping costs, and streamline container orchestration.

## 🚀 About the Project

Efficient load planning is the backbone of a successful supply chain. The **EPPS Container Optimizer** helps logistics planners and supply chain managers visualize, calculate, and optimize the arrangement of goods within standard shipping containers.

* **Maximize Capacity:** Algorithms that prioritize space utilization.
* **Reduce Waste:** Minimize "empty air" in shipments to cut overhead costs.
* **Visual Interface:** Clear, interactive dashboard to see the loading plan before it hits the warehouse floor.

## 🛠️ Tech Stack

This project leverages a modern, high-performance web stack:

## 🚀 Getting Started

### Prerequisites

* [Node.js](https://nodejs.org/) (v18+ recommended)
* npm or yarn

### Installation

1. **Clone the repository:**
```bash
git clone https://github.com/ws0x/epps-sc-container-optimizer.git
cd epps-sc-container-optimizer

```


2. **Install dependencies:**
```bash
npm install

```


3. **Run the development server:**
```bash
npm run dev

```


4. Navigate to the local URL provided in your terminal to access the dashboard.
